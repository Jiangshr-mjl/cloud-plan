## 文件说明

- images/：仅包含 8 张最终定稿，使用稳定文件名。
- HANDOFF.md：实现范围、各页细则、视觉规范、代码入口与验收要求。
- index.html：无需构建、无外部依赖的本地浏览画廊；点击图片打开原图。
- manifest.json：原始来源、PNG 实际尺寸、SHA-256，便于确认文件没有串版。
- prompts/：内置 imagegen 的原始提示词及迭代记录，仅供溯源，不代表要求重新生成。

本交接未提供单独批准的手机图、弹窗图和所有交互状态图；这些界面依据现有行为和本套设计系统适配，不能声称已有像素级批准。
