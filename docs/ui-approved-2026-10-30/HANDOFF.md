# 实施交接：Cloud Plan 蓝白工作台

## 1. 任务目标与范围

在 D:\MyPrograms\Planner\daylight 中，把现有中文个人计划网站更新为本目录批准的 8 张视觉稿。图像由内置 imagegen 生成，用户已经确认整体；不要重新开展风格投票或改成另一套配色。这是 UI 更新，不是重写产品、改变数据模型或新增后台能力。

交付应是可操作、响应式的真实界面，不能把 PNG 当网页背景替代控件。PNG 是视觉依据，文字、图标、轴线、图表、任务和操作用现有 React / CSS / SVG 实现。

## 2. 用户明确确认，必须落实

- 全站蓝白基调，深蓝文字，少量蓝色强调。四象限大面积红绿黄背景已被否定。
- 每日计划右侧「本周重点」条目前的图标必须是小旗子（Lucide Flag），不是文件夹。项目管理里的项目仍可用文件夹。
- 欢迎页两行主文案逐字为「让计划灵活，」「让生活轻盈。」。有同一旧口号的页面标题/元信息一并核查。
- 四象限上方：标题左、新建右；视图选择左、安排日期右；分类筛选在下一行横向均衡分布。
- 四象限是一张共享画布。不要 01/02/03/04 标号，不要四个独立卡片标题栏。
- 中央实线坐标轴：纵轴箭头向上，标「重要程度」；横轴箭头向左，标「紧急程度」。重要性向上增加、紧急性向左增加。
- 外围虚线围合，中央用实线轴清晰分区，不能让项目泡泡遮住轴线。
- 四个标题前仅小圆点使用分类色：左上红、右上橙黄、左下蓝、右下灰。其余画布、项目泡泡、任务卡仍为蓝白。
- 保留椭圆项目气泡、嵌套子项目气泡、可漂浮与可拖动的任务机制。

## 3. 共用视觉系统

以定稿图观感为准，下列数值是可实现的起点，并非精确取色或像素测量结果。

| 用途 | 建议 |
|---|---|
| 页面背景 | #F6F8FC 或近似云白 |
| 内容面 | #FFFFFF |
| 操作与选中 | #2463DB |
| 轻量选中/泡泡 | #ECF3FF / #F3F7FE |
| 正文/标题 | #172B4D |
| 次要文字 | #65758B |
| 普通边界 | #C6D3E3 |
| 坐标轴 | #6687AE，约 2px |
| 外围虚线 | #8CA7C8，约 1–1.5px，约 9px 实线/7px 空隙 |
| 左上/右上/左下/右下小圆点 | #F45B69 / #FFB000 / #2167F3 / #98A2B3 |

- 页面标题使用现代中文无衬线，较粗；不沿用旧界面的大面积宋体/衬线标题。字体优先沿用系统可用中文无衬线，字重与字号用真实渲染对照定稿。
- 标题约 32–40px，区块标题 20–24px，任务 16px，辅助文字 13–14px。不能把生成图中的所有字都过度加粗。
- 顶部导航为浅色横向导航；活动页面蓝色文字/下划线；底部手机导航保留原有可达性。
- 以 8px 节奏组织间距。主体最大宽约 1440px，桌面两侧留白约 64–90px；不是固定写死整张图的坐标。
- 控件圆角约 6–8px，主要控件高度约 40–44px；触屏命中区至少 44px。
- 用细边线、间隔、字重明确层级，避免重阴影、彩色渐变和重复装饰卡片。任务浮层可用很轻的阴影表达可拖动。
- 图标沿用 lucide-react；统一线宽和尺寸。不要为匹配生成图的细小形变另做一套不一致图标。
- 继续遵守 AGENTS.md：减少解释性小字，保留必要日期、状态与风险提示。

## 4. 各页实施细则

### 每日计划：images/01-daily.png

顶部日期、标题和待办数紧凑排列，右侧工作计时与添加任务。七天日期横排，当前日期蓝色突出。主体左宽右窄，左为今日清单，右为本周重点。任务细节和操作按需展开，避免每行全套文字按钮。完成进度轻量化，不再用巨大进度环占位。已完成与往日未完成可折叠。

本周重点全部使用旗子标识。图中的「查看全部项目」如落地，可调用现有切换视图，无需新路由或新接口。保留新增、编辑、完成、排序、拖动改期、备注、截止日期、往日顺延、周重点/项目关联等全部能力；隐藏操作仍需有可发现的入口及键盘访问。

### 项目列表：images/02-project-list.png

用缩进、细层级连线和一致列对齐表现项目—子项目—子任务。进度和截止日期单独对齐。当前展开内容清晰，其他动作收在省略号/上下文菜单。保留添加子项目/子任务、层级拖动、加入周目标、安排到每日、撤回每日、完成与归档、删除确认。项目仍用文件夹，加入周目标的标记用旗子。

### 子任务四象限：images/03-quadrants.png

这是经过最多轮修订的最终定稿，必须优先直接查看。
分类位置保持：左上重要且紧急，右上重要不紧急，左下不重要但紧急，右下不重要不紧急。

坐标轴、外虚线可用同一绝对定位 SVG 或 CSS 叠层实现；图层不拦截指针事件。泡泡布局使用现有测量和碰撞机制，并将每象限内容有效区域扣除标题、安全边距及坐标轴空间，防止移动中穿轴或文字碰线。保持悬停/焦点/详情时暂停相关漂浮，尊重 prefers-reduced-motion。

现有超过 3 个直属子项目的气泡省略规则、拖动迁移、触屏长按及键盘入口必须保留。2026-11-02 用户更新：子任务卡统一白色，取消截止日期及重要程度带来的深浅/透明度变化。不要把截图中「每区一条」当固定数量；检验多条任务、长标题、深层项目及空象限。图中圆点颜色只表达象限类别，与任务截止时间的蓝色深浅是不同编码。

### 时间轴：images/04-timeline.png

保留纵向日期线、日期分组、未安排分组；同日父子项合并显示。展示项目/子任务截止日期和安排信息。生成图中在项目行出现的「加入每日计划」不是新增功能授权：原有只能安排子任务时就仅在可安排子任务上显示此操作。不要增加甘特图、工时排程或项目整体转每日功能。

### 21 天习惯：images/05-habits.png

桌面两列习惯卡，每张严格 21 格（3×7），图区分已打卡、漏打、今天、未来；显示计数/比例/周期与提醒。当天已完成和待完成按钮状态不同。保留编辑、删除、补打、撤销、提醒和本机通知流程；开始日期在已有记录时受既有约束。未来不可打卡；网格编号和日期由实际起始日期计算。提醒需网页打开，不宣传可靠后台推送。21 天是练习周期，不承诺固定养成。

### 工作记录：images/06-work-records.png

顶部今日/本周/近30天时长轻量横排。桌面将每日工作时长和完成量趋势并排，下方搜索、日期筛选、按时间/按项目切换及完成记录。保留每日时长明细、范围切换、类型筛选、导出、点击柱子筛选、撤销完成。

时长记录的是网页运行时间，**不是每条任务耗时**；最终图已去掉虚构的任务时间区间。不得从界面图推导额外的工时模型。完成图分类颜色可按业务区分，不受四象限背景禁用四色的约束。筛选控件外观可参考图，输入语义继续使用现有支持的日期/月范围，不能擅加后端日期范围能力。统计与柱高按真实值渲染。

### 设置与备份：images/07-settings.png

同步、备份、设备密钥三个分区，标题左、字段和操作右。保留同步状态/最近同步/北京时间/数据数量。必须保留导入预览、校验、确认、先备份再替换的流程与提示；工作时长独立导出。忘记本机密钥不删除云端数据。不得展示密钥明文，也不把画面中的普通说明当作改变认证机制的授权。

### 欢迎与解锁：images/08-welcome.png

采用批准的新口号。左侧文案与示意任务，右侧密钥输入、打开计划表。示意任务只用静态虚构内容，不能在解锁前读取真实计划。生成图遗留了登录态导航、示例时间：它们不是功能规格。解锁前维持现有认证边界，可隐藏登录态导航，或确保点击仍停留在解锁界面；不能开放真实设置/任务。示例时间只作为静态演示，不能推导任务新增提醒字段。输入提示、错误、提交中/禁用状态要完整；不增加注册、密码重置或第三方登录。

- 确保键盘操作、可见焦点、文字对比度，颜色之外保留标签；动画降级。
